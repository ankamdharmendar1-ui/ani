Process

How a project actually runs

Four stages, in order, every time. No surprise phases added halfway through.

01 / 04

Discover

A working session to pin down what the site needs to do, for whom, and what "done" looks like.

02 / 04

Build

Design and code happen together, in the browser, so what you review is what ships — not a static mockup.

03 / 04

Launch

Domain, hosting, and a final speed pass. We hand over the keys, not a login you'll never use.

04 / 04

Maintain

Optional monthly care for firms who'd rather call us than learn what a plugin conflict is.
